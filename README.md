# Healjai Repair
### From Flood Damage to Recovery

**Healjai Repair is a flood recovery platform designed to help people affected by flooding assess property damage, estimate potential financial assistance, and find nearby repair and cleaning services.**

Our mission is to make the recovery process simpler, clearer, and more accessible by connecting affected communities with the information and services they need to rebuild.

> **One case. One recovery journey.**

## 🎯 Objectives

- Simplify post-flood recovery for affected individuals and families.
- Help users estimate preliminary damage and potential financial assistance.
- Connect users with local repair and cleaning service providers.
- Improve access to insurance claim and government assistance information.
- Support a more transparent and organized recovery process.

## 👥 Target Users

- **Flood survivors:** People needing recovery information and repair services.
- **Homeowners and vehicle owners:** People assessing damage and estimating repair costs.
- **Service providers:** Repair technicians, mechanics, renovation contractors, and cleaning companies.
- **Community organizations:** Groups supporting flood recovery and disaster relief.

## ✨ Key Features

### 1. Damage Assessment
- Record flood damage to homes and vehicles.
- Upload photos and provide location details.
- Review an initial damage summary.

### 2. Insurance and Assistance Estimator
- Estimate preliminary recovery and repair costs.
- Explore relevant insurance and government assistance resources.
- Identify potentially required supporting documents.

*Estimates are for preliminary planning only and do not guarantee insurance compensation or government assistance.*

### 3. Find Nearby Repair Services
- Home renovation and repair
- Vehicle repair and mechanics
- Post-flood house cleaning
- Electrical, plumbing, and maintenance services

### 4. Service Requests and Quotations
- Submit repair or cleaning requests.
- Review provider information.
- Request and compare quotations.
- Track service progress where supported.

## 🔄 Core User Flow

**Assess Damage → Estimate Costs → Find Services → Recover**

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- [React.js](https://react.dev/)

### Installation

Clone the repository:

```bash
git clone https://github.com/tingjhaa/healjairepair.github.io.git
```

Navigate to the project directory:

```bash
cd healjairepair.github.io
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

*Note: These commands assume the repository contains a compatible `package.json` with the required scripts.*
